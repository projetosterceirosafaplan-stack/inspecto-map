# Field Report Pro

Preciso de um programa de fiscalização, onde eu vou a campo, fiscalizo postes de um asbuilt e gero um relatório de pendencias construtivas. Coloquei um anexo de lista de pendencias, onde deve adicionar no poste uma das pendencias caso seja encontrada.  Após feita a fiscalização, deve ser posível fazer um relatorio fotográfico de pendencias, onde deve seguir o formato do relatorio em anexo. A fiscalização deve ser feita no google maps, colocando pontos e trechos, cada ponto deve ter um campo de fotos e seja possivel ir adiiconando uma das pendencias da lista. Cada pendencias deve ter sua propria foto como evidencias que deve ser pontuada no relatorio fotografico
